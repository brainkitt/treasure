Verdict

  • Overall winner: IDX "IndexDipBuy" (US indices), score 72.4/100. It has the most trades, the strongest t-statistic (3.25), the best out-of-sample profit factor (2.19), and passed every gate. The same frozen rules also worked on US Tech 100, which was never used to build it.
  • Runner-up: CFX "Crypto Momentum Burst" (ETHUSD H1), score 66.0/100. It also passes every gate, needs the smallest account of the two ($300), and never pays swap. Its weakness is that profits come in bursts from a handful of large trades.
  • VOL (Deriv synthetics): no bot is recommended. Across two research rounds and about 7,100 backtests, nothing survived costs. Drift Switch indices trend for a few minutes at a time (real before costs, momentum t-stats of 8 to 12), but Deriv's spread widens by about the capturable move exactly when they trend, so the official result is PF 0.65. Holding longer did not help because the regimes last minutes, not hours. Volatility 75 and the other synthetics behaved like fair games. VolBot.cs is included for reference only; do not run it with money.
  • $30 is not achievable responsibly with any edge found. Every strategy that fits a $30 account (FX at 0.01 lot, synthetics at minimum volume) lost money after costs on multi-year data. The real edges need wider stops than a $30 account can absorb at the broker's minimum volume. The smallest responsible accounts are $300 (CFX) and $700 (IDX), or $250 for the IDX small-cap-only variant.
  • Both qualified bots run at the broker's minimum volume. Dollar drawdowns stay the same however big the account is, so a larger account only lowers the percentage risk. Running both together diversifies across markets: $1,000–$1,700 covers both comfortably.
  • Nothing here is guaranteed. Expect forward profit factors of about 1.3–1.5, below the backtests, and run each bot on the demo account for 2–6 months before using real money.

Best timeframe per bot

  • IDX: H1 chart, one decision per day at the H1 bar opening 14:00 New York (closes 15:00 NY). 12:00 NY was weaker (PF 1.51); M15 added nothing.
  • CFX: H1 chart. On H2/H4 the effect is gone (PF 0.87), because the follow-through lasts about 3 hours.
  • VOL: M5 was the only timeframe with a gross edge, and the spread erased it.

Ride the 3 hours after an abnormally large ETHUSD H1 candle (|body| > 2.5x 24h mean range), hard stop 2x ATR, never held through 20:00-22:59 UTC rollover.

Entry

Exit
Time exit at the close of the 3rd H1 bar (3 hours after entry) unless the stop is hit first.
Stop
Hard server-side stop = 2.0 x ATR24 from entry (median ~$7-8 at 0.1 ETH; worst realised loss $8.56).
Take Profit
None (a 2x ATR TP was tested and reduced OOS PF).
Sizing
Fixed broker minimum 0.1 ETH. cBot option: risk-% sizing, never below minimum, capped by MaxRiskPercent (4%) and MaxVolumeUnits.
Risk
One position; daily loss limit 5% of day-start balance; equity kill-switch at -25% from peak (closes and stops the bot); pause 48h after 6 consecutive losses; spread filter; recommended balance $300 (evaluator recommended_min $285, technical_min $107).

AGENT_03 · Volatility Indices Specialist

VOL Drift-Switch regime trend follower (NOT QUALIFIED - no edge net of dynamic spread)

Real, documented regime persistence on Deriv Drift Switch indices gives a strong GROSS momentum edge, but Deriv's dynamic spread widens during drift regimes and consumes it; not tradable.

Trading logic

Entry

How the competition was run

Setup

  • Three independent agents each owned one market. They could read but not change each other's work, and could not change the scoring code.
  • Data came from your Deriv cTrader demo account through MCP: H1 history back to 2023–2024, plus M15/M5/M1 where needed. Your own closed-trade history (Oct–Nov 2026) was analysed as well.
  • One scoring engine was used for everyone. It runs on BID bars and is deliberately pessimistic: if the stop and target fall in the same bar, it counts the stop; stops slip; spike instruments fill at the bar extreme.
  • Costs charged: the widest live spread sampled, commission (0 on this account, verified from 150+ deals), swap per night held (a conservative bound where Deriv does not publish rates), and slippage.
  • Broker minimum volumes were confirmed with limit-order probes far from market. Each probe was rejected or cancelled immediately, and no position was ever opened. Your live XAUUSD "G2" position was not touched.

Validation (15 gates, all must pass)

  • Profit factor ≥ 1.30 on the full sample, and ≥ 1.20 on both the first 70% (fitting) and the last 30% (unseen).
  • Profit factor ≥ 1.10 with spread × 1.5 plus extra slippage.
  • ≥ 100 trades, ≥ 30 of them out-of-sample. At least 4 of 5 equal time folds profitable.
  • Expectancy t-statistic ≥ 2.0.
  • Max drawdown ≤ 25% of the start balance; 95th-percentile Monte Carlo drawdown (5,000 reshuffles) ≤ 35%.
  • Worst trade ≤ 5% of the start balance.
  • No look-ahead: signals recomputed on truncated history must match.
  • Minimum lot respected; swap known for overnight holds; margin ≤ 50% of balance.
  • On top of the gates, each agent ran an anchored walk-forward that re-fitted parameters fold by fold, reported neighbouring-parameter results, counted every parameter set tried, and tried to disprove its own best idea.

When to stop a bot (pre-committed)

  • Built-in: an equity kill-switch at 25% below peak; a daily loss limit (IDX 8%, CFX 5%); a pause after a losing streak (IDX 7 losses, CFX 6 losses, then 48 h); a planned-risk cap per trade; a spread filter.
  • IDX: review if drawdown passes $77 (the 95% Monte Carlo level) or if the US market enters a sustained bear trend (for example SP 500 below its 200-day average for a month). A long-only dip buyer is most exposed then.
  • CFX: review if drawdown passes $46, or if PF over the last 40 trades drops below 1.0. Long flat stretches are normal for this bot.
  • Compare live fills with the backtest every month: spread paid, swap charged, slippage on stops.
  • Never add martingale, grid or averaging-down logic. None of the tested edges needs it.
Known weaknesses. IDX was tested only in a rising equity market (2024–2026), and its worst loss came on a crash day (3 Apr 2025, −$33.84). Its swap charge is an estimate: Deriv's index swap rates were not visible, so it uses a 7.5%/year bound. CFX depends on a few large trades (PF 1.40 without its best 5, 1.11 without its best 10). It lost money in the second half of 2023 and was flat from June to November 2026. Its night and weekend spreads were never measured. Both bots were researched with thousands of parameter trials (IDX about 6,300, CFX about 830). The walk-forward tests, neighbouring-parameter tests and out-of-sample replication reduce the chance of a curve-fit but cannot rule it out.

// IdxBot - "IndexDipBuy" (arena v2, agent IDX)
// -----------------------------------------------------------------------------------------------
// Buys a US equity-index CFD after a short-term washout and exits one session later.
// Exactly the logic of agents/IDX/strategy.py:
//   * Attach to an H1 chart of "US SP 500" or "US Small Cap 2000" (one instance per symbol).
//   * A "session" ends with the H1 bar that OPENS at SignalHourNY (default 14:00 New York, DST-aware);
//     session close = close of that bar (price at 15:00 NY, one hour before the cash close).
//   * Signal (evaluated once, when that bar has closed): session close <= lowest of the last N (=7) session
//     closes (including today) -> BUY at market.
//   * SL = SlAtr (3.0) x ATR14(sessions), TP = TpAtr (0.75) x ATR14, time exit at the close of the
//     HoldBars-th (22nd) H1 bar after the fill bar (= next session's 15:00 NY close). Long only.
//     ATR14 = simple mean of the last 14 session true ranges (session high/low vs previous session close).
//   * Volume = broker minimum (Symbol.VolumeInUnitsMin, 0.1 unit) unless risk-% sizing is enabled.
// Safety (none of these triggered in the 2024-05..2026-11 backtest, so they do not change the tested logic):
//   hard SL+TP on every order, spread filter, one position per symbol per label, duplicate-order guard,
//   daily loss limit, equity drawdown kill-switch, consecutive-loss pause, planned-risk cap.
// All times are handled in UTC (TimeZone = UTC); New York time is computed with the US DST rule.
// -----------------------------------------------------------------------------------------------
using System;
using System.Collections.Generic;
using System.Linq;
using cAlgo.API;
using cAlgo.API.Internals;

namespace cAlgo.Robots
{
    [Robot(TimeZone = TimeZones.UTC, AccessRights = AccessRights.None)]
    public class IdxBot : Robot
    {
        // ---- strategy -------------------------------------------------------------------------
        [Parameter("Lookback sessions N", Group = "Strategy", DefaultValue = 7, MinValue = 3, MaxValue = 20)]
        public int LookbackN { get; set; }

        [Parameter("ATR period (sessions)", Group = "Strategy", DefaultValue = 14, MinValue = 5, MaxValue = 50)]
        public int AtrPeriod { get; set; }

        [Parameter("Stop loss (x ATR)", Group = "Strategy", DefaultValue = 3.0, MinValue = 1.0, MaxValue = 6.0, Step = 0.25)]
        public double SlAtr { get; set; }

        [Parameter("Take profit (x ATR, 0 = none)", Group = "Strategy", DefaultValue = 0.75, MinValue = 0.0, MaxValue = 3.0, Step = 0.25)]
        public double TpAtr { get; set; }

        [Parameter("Time exit after H1 bars", Group = "Strategy", DefaultValue = 22, MinValue = 1, MaxValue = 200)]
        public int HoldBars { get; set; }

        [Parameter("Signal bar open hour (New York)", Group = "Strategy", DefaultValue = 14, MinValue = 0, MaxValue = 23)]
        public int SignalHourNY { get; set; }

        [Parameter("Min H1 bars per session", Group = "Strategy", DefaultValue = 10, MinValue = 1, MaxValue = 24)]
        public int MinBarsPerSession { get; set; }

        // ---- sizing ---------------------------------------------------------------------------
        [Parameter("Use risk-% sizing", Group = "Sizing", DefaultValue = false)]
        public bool UseRiskSizing { get; set; }

        [Parameter("Risk per trade (% balance)", Group = "Sizing", DefaultValue = 2.0, MinValue = 0.1, MaxValue = 10.0)]
        public double RiskPercent { get; set; }

        [Parameter("Max volume (units)", Group = "Sizing", DefaultValue = 1.0, MinValue = 0.01)]
        public double MaxVolumeUnits { get; set; }

        [Parameter("Skip if planned risk > % balance", Group = "Sizing", DefaultValue = 12.0, MinValue = 0.5, MaxValue = 50.0)]
        public double MaxRiskCapPercent { get; set; }

        // ---- protection -----------------------------------------------------------------------
        [Parameter("Max spread (price units)", Group = "Protection", DefaultValue = 1.0, MinValue = 0.0)]
        public double MaxSpread { get; set; }

        [Parameter("Daily loss limit (% balance)", Group = "Protection", DefaultValue = 8.0, MinValue = 0.5, MaxValue = 50.0)]
        public double DailyLossLimitPercent { get; set; }

        [Parameter("Equity kill-switch DD (% of peak)", Group = "Protection", DefaultValue = 25.0, MinValue = 2.0, MaxValue = 90.0)]
        public double MaxEquityDrawdownPercent { get; set; }

        [Parameter("Pause after consecutive losses", Group = "Protection", DefaultValue = 7, MinValue = 1, MaxValue = 50)]
        public int MaxConsecutiveLosses { get; set; }

        [Parameter("Pause length (sessions)", Group = "Protection", DefaultValue = 5, MinValue = 1, MaxValue = 60)]
        public int PauseSessions { get; set; }

        [Parameter("Label", Group = "Protection", DefaultValue = "IDX-DipBuy")]
        public string LabelBase { get; set; }

        // ---- state ----------------------------------------------------------------------------
        private string _label;
        private double _peakEquity;
        private bool _killed;
        private bool _orderInFlight;
        private int _consecLosses;
        private DateTime _pauseUntilUtc = DateTime.MinValue;
        private DateTime _lastSignalBarTime = DateTime.MinValue;
        private DateTime _dayStartUtc = DateTime.MinValue;
        private double _dayStartBalance;

        private class Session
        {
            public DateTime Key;
            public double High, Low, Close;
            public int LastIndex, LastHourNY, Count;
        }

        protected override void OnStart()
        {
            _label = LabelBase + "-" + SymbolName;
            _peakEquity = Account.Equity;
            _dayStartUtc = Server.Time.Date;
            _dayStartBalance = Account.Balance;

            if (TimeFrame != TimeFrame.Hour)
                Print("WARNING: IdxBot was designed and tested on H1 bars; current timeframe = {0}.", TimeFrame);

            // make sure enough history for N + ATR sessions (~23 bars per session)
            int needBars = (LookbackN + AtrPeriod + 5) * 24;
            int guard = 0;
            while (Bars.Count < needBars && guard++ < 20)
            {
                int loaded = Bars.LoadMoreHistory();
                if (loaded <= 0) break;
            }

            Positions.Closed += OnPositionClosed;
            Print("IdxBot started on {0} {1}. Label={2}, bars={3}, volume min={4} units, N={5}, SL={6}xATR, TP={7}xATR, hold={8} bars, signal hour NY={9}",
                  SymbolName, TimeFrame, _label, Bars.Count, Symbol.VolumeInUnitsMin, LookbackN, SlAtr, TpAtr, HoldBars, SignalHourNY);
        }

        protected override void OnStop()
        {
            Positions.Closed -= OnPositionClosed;
            Print("IdxBot stopped. Open positions with label {0}: {1}", _label, Positions.FindAll(_label, SymbolName).Length);
        }

        protected override void OnTick()
        {
            CheckEquityKillSwitch();
        }

        protected override void OnBar()
        {
            // OnBar fires when a new bar opens; Bars.Last(1) is the bar that just closed.
            RollDay();
            CheckEquityKillSwitch();
            ManageTimeExit();
            if (_killed) return;

            int closedIdx = Bars.Count - 2;
            if (closedIdx < 1) return;
            DateTime closedOpenUtc = Bars.OpenTimes[closedIdx];
            if (ToNewYork(closedOpenUtc).Hour != SignalHourNY) return;
            if (closedOpenUtc == _lastSignalBarTime) return;          // duplicate guard (one decision per bar)
            _lastSignalBarTime = closedOpenUtc;

            List<Session> ses = BuildSessions(closedIdx);
            if (ses.Count < Math.Max(LookbackN, AtrPeriod + 1) + 1)
            {
                Print("Not enough complete sessions ({0}) - no decision.", ses.Count);
                return;
            }
            Session today = ses[ses.Count - 1];
            if (today.LastIndex != closedIdx) return;                 // the closed bar must end a valid session

            double atr = SessionAtr(ses);
            double lowest = double.MaxValue;
            for (int k = ses.Count - LookbackN; k < ses.Count; k++)
                lowest = Math.Min(lowest, ses[k].Close);
            bool signal = today.Close <= lowest && atr > 0;
            Print("Session {0:yyyy-MM-dd} close={1} lowest{2}={3} ATR={4:F2} -> {5}", today.Key, today.Close, LookbackN, lowest, atr,
                  signal ? "SIGNAL" : "no signal");
            if (!signal) return;

            TryEnter(atr);
        }

        // ------------------------------------------------------------------------------------
        private void TryEnter(double atr)
        {
            if (_orderInFlight) { Print("Order already in flight - skip."); return; }
            if (Positions.FindAll(_label, SymbolName).Length > 0) { Print("Position already open for {0} - skip.", _label); return; }
            if (Server.Time < _pauseUntilUtc) { Print("Paused after {0} consecutive losses until {1:u} - skip.", MaxConsecutiveLosses, _pauseUntilUtc); return; }
            if (DailyLossHit()) { Print("Daily loss limit reached - skip."); return; }

            double spread = Symbol.Ask - Symbol.Bid;
            if (MaxSpread > 0 && spread > MaxSpread) { Print("Spread {0} > max {1} - skip.", spread, MaxSpread); return; }

            double slDist = SlAtr * atr;
            double tpDist = TpAtr * atr;
            double valuePerUnitPerPrice = Symbol.TickValue / Symbol.TickSize;   // account currency per 1 unit per 1.0 price
            double volume = Symbol.VolumeInUnitsMin;
            if (UseRiskSizing)
            {
                double riskMoney = Account.Balance * RiskPercent / 100.0;
                double raw = riskMoney / (slDist * valuePerUnitPerPrice);
                volume = Math.Min(raw, MaxVolumeUnits);
                volume = Symbol.NormalizeVolumeInUnits(volume, RoundingMode.Down);
                if (volume < Symbol.VolumeInUnitsMin) volume = Symbol.VolumeInUnitsMin;
            }
            double plannedRisk = slDist * valuePerUnitPerPrice * volume;
            if (plannedRisk > Account.Balance * MaxRiskCapPercent / 100.0)
            {
                Print("Planned risk {0:F2} > cap {1}% of balance {2:F2} - skip.", plannedRisk, MaxRiskCapPercent, Account.Balance);
                return;
            }

            double slPips = Math.Round(slDist / Symbol.PipSize, 1);
            double? tpPips = tpDist > 0 ? Math.Round(tpDist / Symbol.PipSize, 1) : (double?)null;
            _orderInFlight = true;
            TradeResult res = ExecuteMarketOrder(TradeType.Buy, SymbolName, volume, _label, slPips, tpPips, "IndexDipBuy");
            _orderInFlight = false;
            if (!res.IsSuccessful || res.Position == null)
            {
                Print("ORDER FAILED: {0}", res.Error);
                return;
            }
            Position p = res.Position;
            if (p.StopLoss == null)
            {
                Print("Position {0} has no stop loss attached - closing for safety.", p.Id);
                ClosePosition(p);
                return;
            }
            Print("BUY {0} units @ {1} SL={2} TP={3} (ATR={4:F2}, planned risk {5:F2})", volume, p.EntryPrice, p.StopLoss, p.TakeProfit, atr, plannedRisk);
        }

        private void ManageTimeExit()
        {
            int cur = Bars.Count - 1;   // index of the bar that just opened
            foreach (Position p in Positions.FindAll(_label, SymbolName))
            {
                int entryIdx = Bars.OpenTimes.GetIndexByTime(p.EntryTime);
                if (entryIdx < 0) continue;
                // close at the close of the HoldBars-th bar after the fill bar == open of bar entryIdx + HoldBars + 1
                if (cur - entryIdx >= HoldBars + 1)
                {
                    TradeResult r = ClosePosition(p);
                    if (r.IsSuccessful) Print("Time exit position {0} after {1} bars, net {2:F2}", p.Id, cur - entryIdx - 1, p.NetProfit);
                    else Print("Time exit FAILED for {0}: {1}", p.Id, r.Error);
                }
            }
        }

        private void OnPositionClosed(PositionClosedEventArgs args)
        {
            Position p = args.Position;
            if (p.Label != _label || p.SymbolName != SymbolName) return;
            if (p.NetProfit < 0) _consecLosses++; else _consecLosses = 0;
            Print("Closed {0}: net {1:F2} ({2}); consecutive losses = {3}", p.Id, p.NetProfit, args.Reason, _consecLosses);
            if (_consecLosses >= MaxConsecutiveLosses)
            {
                _pauseUntilUtc = Server.Time.AddDays(PauseSessions * 7.0 / 5.0);
                _consecLosses = 0;
                Print("Consecutive-loss limit hit: pausing new entries until {0:u}", _pauseUntilUtc);
            }
        }

        private void RollDay()
        {
            if (Server.Time.Date != _dayStartUtc)
            {
                _dayStartUtc = Server.Time.Date;
                _dayStartBalance = Account.Balance;
            }
        }

        private bool DailyLossHit()
        {
            double floating = Positions.Where(x => x.Label != null && x.Label.StartsWith(LabelBase)).Sum(x => x.NetProfit);
            double dayPnl = Account.Balance - _dayStartBalance + floating;
            return dayPnl <= -_dayStartBalance * DailyLossLimitPercent / 100.0;
        }

        private void CheckEquityKillSwitch()
        {
            if (_killed) return;
            if (Account.Equity > _peakEquity) _peakEquity = Account.Equity;
            if (Account.Equity < _peakEquity * (1.0 - MaxEquityDrawdownPercent / 100.0))
            {

                Print("EQUITY KILL-SWITCH: equity {0:F2} < {1}% below peak {2:F2}. Closing positions and stopping.", Account.Equity, MaxEquityDrawdownPercent, _peakEquity);

        // ---- sessions / indicators ------------------------------------------------------------
        private List<Session> BuildSessions(int lastIdx)
        {
            // session key = New-York date of (bar time + (24 - (SignalHourNY + 1)) hours): the session ending with
            // the SignalHourNY bar starts with the bar opening at SignalHourNY+1 NY on the previous day.
            int need = (LookbackN + AtrPeriod + 5) * 24;
            int start = Math.Max(0, lastIdx - need);
            var list = new List<Session>();
            Session cur = null;
            for (int i = start; i <= lastIdx; i++)
            {
                DateTime ny = ToNewYork(Bars.OpenTimes[i]);
                DateTime key = ny.AddHours(24 - (SignalHourNY + 1)).Date;
                if (cur == null || key != cur.Key)
                {
                    if (cur != null) list.Add(cur);
                    cur = new Session { Key = key, High = Bars.HighPrices[i], Low = Bars.LowPrices[i], Close = Bars.ClosePrices[i], LastIndex = i, LastHourNY = ny.Hour, Count = 1 };
                }
                else
                {
                    cur.High = Math.Max(cur.High, Bars.HighPrices[i]);
                    cur.Low = Math.Min(cur.Low, Bars.LowPrices[i]);
                    cur.Close = Bars.ClosePrices[i];
                    cur.LastIndex = i;
                    cur.LastHourNY = ny.Hour;
                    cur.Count++;
                }
            }
            if (cur != null) list.Add(cur);
            if (list.Count > 0) list.RemoveAt(0);   // first session may be truncated by the history window
            return list.Where(s => s.Count >= MinBarsPerSession && s.LastHourNY == SignalHourNY).ToList();
        }

        private double SessionAtr(List<Session> s)
        {
            int n = s.Count;
            double sum = 0;
            for (int k = n - AtrPeriod; k < n; k++)
            {
                double pc = s[k - 1].Close;
                double tr = Math.Max(s[k].High - s[k].Low, Math.Max(Math.Abs(s[k].High - pc), Math.Abs(s[k].Low - pc)));
                sum += tr;
            }
            return sum / AtrPeriod;
        }

        // US Eastern time from UTC (rule since 2007: DST from 2nd Sunday of March 02:00 to 1st Sunday of November 02:00)
        private static DateTime ToNewYork(DateTime utc)
        {
            int y = utc.Year;
            DateTime mar1 = new DateTime(y, 3, 1);
            DateTime dstStart = mar1.AddDays(((7 - (int)mar1.DayOfWeek) % 7) + 7).AddHours(7);   // 02:00 EST = 07:00 UTC
            DateTime nov1 = new DateTime(y, 11, 1);
            DateTime dstEnd = nov1.AddDays((7 - (int)nov1.DayOfWeek) % 7).AddHours(6);            // 02:00 EDT = 06:00 UTC
            bool dst = utc >= dstStart && utc < dstEnd;
            return utc.AddHours(dst ? -4 : -5);
        }

            if (_killed) return;

            int last = Bars.Count - 2;          // index of the bar that just CLOSED (Bars.Last(1))
            if (last < Math.Max(N, AtrPeriod) + 2) return;

            var pos = MyPosition();
            double atr = Atr(last);

            // ---- manage open position on bar close: time exit, then trailing stop ----
            if (pos != null)
            {
                if (_entryBar >= 0 && last - _entryBar >= MaxBars)   // engine: close at the close of the MaxBars-th bar after the fill bar
                {
                    Print("Time exit after {0} bars", last - _entryBar);
                    CheckResult(ClosePosition(pos), "close (time)");
                    return;
                }
                if (TrailAtr > 0 && atr > 0 && pos.StopLoss.HasValue && last > _entryBar)   // engine never ratchets on the fill bar's close
                {
                    double trail = TrailAtr * EntryAtr(pos, atr);
                    double close = Bars.ClosePrices[last];
                    if (pos.TradeType == TradeType.Buy)
                    {
                        double ns = Math.Round(close - trail, Symbol.Digits);
                        if (ns > pos.StopLoss.Value + Symbol.TickSize)
                            CheckResult(ModifyPosition(pos, ns, pos.TakeProfit, ProtectionType.Absolute), "trail long");

                    else
                    {

                        if (ns < pos.StopLoss.Value - Symbol.TickSize)
                            CheckResult(ModifyPosition(pos, ns, pos.TakeProfit, ProtectionType.Absolute), "trail short");
                    }
                }
                return; // one position at a time
            }

            if (_orderInFlight) return;
            if (last < _pauseUntilBar) return;
            if (DailyLossHit()) return;
            int h = Bars.OpenTimes[last + 1].Hour;
            if (InNoEntryWindow(h)) return;
            if (!WindowClean(last)) return;

            TradeType? side = null;
            if (er > Threshold) side = TradeType.Buy;
            else if (AllowShorts && er < -Threshold) side = TradeType.Sell;
            if (side == null) return;

            if (Symbol.Spread > MaxSpread)
            {
                Print("Signal {0} er={1:F2} skipped: spread {2:F2} > {3}", side, er, Symbol.Spread, MaxSpread);
                return;

            }

        private double Atr(int last)
        {
            double s = 0;
            for (int k = last - AtrPeriod + 1; k <= last; k++) s += Bars.HighPrices[k] - Bars.LowPrices[k];
            return s / AtrPeriod;

        // ATR at entry is stored in the comment so that the trail distance matches strategy.py (fixed at entry)
        private double EntryAtr(Position p, double fallback)
        {
            try
            {
                var c = p.Comment ?? "";
                int i = c.IndexOf("atr=", StringComparison.Ordinal);
                if (i >= 0) return double.Parse(c.Substring(i + 4), System.Globalization.CultureInfo.InvariantCulture);
            }
            catch (Exception) { }
            return fallback;
        }

        private double EfficiencyRatio(int last)
        {
            double path = 0;
            for (int k = last - N + 1; k <= last; k++) path += Math.Abs(Bars.ClosePrices[k] - Bars.ClosePrices[k - 1]);
            double net = Bars.ClosePrices[last] - Bars.ClosePrices[last - N];
            return path > 0 ? net / path : 0;

        private bool WindowClean(int last)
        {
            double barSec = (Bars.OpenTimes[last] - Bars.OpenTimes[last - 1]).TotalSeconds;
            double nominal = TimeFrameSeconds();
            int w = Math.Max(N, AtrPeriod);
            for (int k = last - w + 1; k <= last; k++)
                if ((Bars.OpenTimes[k] - Bars.OpenTimes[k - 1]).TotalSeconds > 1.5 * nominal) return false;
            return barSec > 0;
        }

        private double TimeFrameSeconds()
        {
            if (TimeFrame == TimeFrame.Minute) return 60;
            if (TimeFrame == TimeFrame.Minute5) return 300;
            if (TimeFrame == TimeFrame.Minute15) return 900;
            if (TimeFrame == TimeFrame.Minute30) return 1800;
            if (TimeFrame == TimeFrame.Hour) return 3600;
            return 300;
        }

        private bool InNoEntryWindow(int hour)
        {
            if (NoEntryFromHour == NoEntryToHour) return false;
            if (NoEntryFromHour < NoEntryToHour) return hour >= NoEntryFromHour && hour < NoEntryToHour;
            return hour >= NoEntryFromHour || hour < NoEntryToHour;
        }

        private double Volume(double stopDist)
        {
            double min = Symbol.VolumeInUnitsMin;
            double vol = VolumeUnits > 0 ? VolumeUnits : min;
            if (RiskPercent > 0 && stopDist > 0)
            {
                double riskCash = Account.Balance * RiskPercent / 100.0;
                double perUnit = stopDist / Symbol.TickSize * Symbol.TickValue; // account ccy lost per unit at the stop
                if (perUnit > 0) vol = riskCash / perUnit;
            }
            vol = Symbol.NormalizeVolumeInUnits(Math.Max(vol, min), RoundingMode.Down);
            if (vol < min) vol = min;
            // never exceed the max-risk cap; if even the minimum exceeds it, do not trade
            double capCash = Account.Balance * MaxRiskPercent / 100.0;
            double riskAtVol = stopDist / Symbol.TickSize * Symbol.TickValue * vol;
            while (riskAtVol > capCash && vol > min)
            {
                vol = Symbol.NormalizeVolumeInUnits(vol - Symbol.VolumeInUnitsStep, RoundingMode.Down);
                riskAtVol = stopDist / Symbol.TickSize * Symbol.TickValue * vol;
            }
            if (riskAtVol > capCash)
            {
                Print("Risk at minimum volume {0:F2} exceeds cap {1:F2} - skip", riskAtVol, capCash);
                return 0;
            }
            return vol;
        }

        private void RollDay()
        {
            if (Server.Time.Date != _day)
            {
                _day = Server.Time.Date;
                _dayStartBalance = Account.Balance;
            }
        }

        private bool DailyLossHit()
        {
            if (DailyLossLimit <= 0) return false;
            double lost = _dayStartBalance - Account.Equity;
            if (lost >= DailyLossLimit)
            {
                Print("Daily loss limit reached ({0:F2} >= {1}) - no new entries today", lost, DailyLossLimit);
                return true;
            }
            return false;
        }

        private void OnPositionClosed(PositionClosedEventArgs e)
        {
            var p = e.Position;
            if (p.Label != Label || p.SymbolName != SymbolName) return;
            _entryBar = -1;
            if (p.NetProfit < 0) _consecLosses++; else _consecLosses = 0;
            Print("CLOSED {0} net {1:F2} ({2}); consecutive losses {3}", p.TradeType, p.NetProfit, e.Reason, _consecLosses);
            if (MaxConsecutiveLosses > 0 && _consecLosses >= MaxConsecutiveLosses)
            {
                _pauseUntilBar = Bars.Count - 1 + PauseBars;
                _consecLosses = 0;
                Print("Pausing entries for {0} bars after {1} consecutive losses", PauseBars, MaxConsecutiveLosses);
            }
        }

        private bool CheckResult(TradeResult r, string what)
        {
            if (r == null) { Print("{0}: null result", what); return false; }
            if (!r.IsSuccessful) { Print("{0} FAILED: {1}", what, r.Error); return false; }
            return true;
        }
